Record that file read and the contract version in the startup receipt. An embedded profile contract is not a substitute for this current on-disk read. Do not redispatch this entry skill into another researcher. The dispatch steps below belong to the caller.

1. Read [the mandatory contract](references/contract.md), [workflow integration](references/pstack.md) and [independent review protocol](references/review.md), [workflow receipt](references/workflow.md), and [original evidence preservation](references/evidence.md), [prior-work checkpoint](references/prior-work.md), and [caller boundaries](references/coordinator.md). Before dispatch and after return, apply the prior-work comparison in references/coordinator.md: closest evidence, outcome/limits, remaining question/delta and smallest justified action. This also governs follow-ups and short suggestions; missing history is unverified, not new.

3. Resolve the source checkout as the parent of the resolved `project-research` skill directory, not the skill directory itself. The helper is `<source>/scripts/manage.py`; inspect that actual path before claiming it is absent. For a personal profile, run `python3.12 <source>/scripts/manage.py check-profile --profile <actual-profile-file>`. File checks do not prove compliance. For other supported installations, use equivalent source/profile consistency evidence.
4. Inspect the host's actual profile-selection capability. Launch `project-researcher` with `agent_type: "project-researcher"`, `fork_turns: "none"`, this skill's absolute path, and a standalone question and live context. Do not launch a CLI subprocess, generic persona, or parent substitute if actual selection is unavailable. Return a startup limitation.
5. Wait for the report. Inspect its decisive sources and fresh-review receipt before conveying findings at their stated evidence level. Requested-only context settings must remain source-reviewed-context-unverified; do not upgrade an authored receipt into host confirmation. If the child returns `review-required`, arrange the review described in references/review.md. Do not turn partial findings into verified conclusions.
