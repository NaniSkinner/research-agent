# Preserve evidence before summarizing

This reference governs preservation, not research orchestration. Installed Pstack still owns workflow and roles. Capture only evidence allowed by the live task, in the declared run-owned output directory; do not copy credentials, unrelated history, restricted diagnostics or protected materials to close an evidence gap.

## Record the returned evidence

As each consequential tool/check or delegated lane returns, preserve its actual returned value before writing a narrative summary. Save exact worker output text separately from the lead's explanation, edits or synthesis. Preserve the full returned output, error/exit fields, command and working directory, and any item/worker/source identifiers the supported surface exposes. JSON serialization may change wire formatting but must not rewrite, shorten or replace field values. Retain existing truncation flags and original-size metadata; do not describe a truncated export as a complete original tool response.

Use these distinct evidence kinds in a small evidence-index table:

| Kind | Required identity and limit |
| --- | --- |
| Original returned tool value | Actual supported tool/call identifier if exposed, capture location and fields preserved; no missing host fields invented |
| Original worker return | Worker/turn/result identifier and exact output file; identify whether text came directly from completion or a supported exported final message |
| Supported history export | Tool, parameters, thread/turn/item IDs and page limits; preserve returned selected items without rewriting fields; disclose retrospective capture, truncation, omitted items and unavailable raw dispatch/approval metadata |
| Lead summary/transcription | Clearly authored interpretation with pointers to originals; never the sole proof of activity when original evidence is available |

A summary with a command, exit zero, worker name or copied hash is not an original receipt. Do not relabel a reconstructed transcription as captured raw output. Do not replace originals with excerpts merely to keep the final answer short; retain allowed originals in files and link the concise answer to them. An excerpt or safety-redacted derivative must point to its allowed source and describe omissions, without claiming completeness.

## Before freezing a review packet

Include the evidence index and exact completed outputs for every consequential discovery/explanation lane, plus original check/connector receipts supporting operational claims. Use additional evidence roles in the existing packet helper; preserve the brief/report/ledger/explanation/workflow roles. A lead-written synthesis does not replace the original explainer result. Keep the original worker artifact even when the presented explanation is edited.

The caller owns any supported export capability unavailable to a child. Request a scoped export of needed item IDs/worker returns from that caller before review. Export only the relevant commands/results/lifecycle events; exclude private reasoning, entire author conversations and earlier independent-review verdicts. Do not access private host stores or retrieve prohibited material. Earlier research findings are claims to check, not a supplied passing verdict.

If an original cannot be safely obtained, record the exact missing receipt and affected claims. Preserve those as reported-not-reverified and workflow provenance partial; a source-reviewed report may still return useful bounded facts. Do not invent receipts, repeat an investigation/check/model run to manufacture historical proof, or treat new execution as proof of old execution. Supplied hashes establish identity of files, not truth, host isolation or a complete event history.

The fresh reviewer checks the index against packet contents, identifies which originals/exports it actually opened, verifies decisive source facts and retains any missing provenance. Preserve its actual completion text before reconciliation. Repaired packets get a new directory/identity; never overwrite prior packets, original worker returns or review results. Capturing a missing original is an evidence repair, not authority to rerun research or expand access.
